# Scaffold and Shared Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the portfolio scaffold, shared shell, motion primitives, typed content, and navigable page placeholders.

**Architecture:** Vite builds a strict React/TypeScript app. BrowserRouter uses the deployment base. Shared components consume CSS tokens and typed content; pages remain intentionally small.

**Tech Stack:** React, TypeScript, Vite, React Router, Motion, plain CSS, Fontsource.

**Spec:** `AGENTS.md`, `DESIGN.md`, `MOTION.md`, `CONTENT.md`, `TOKENS.md`, and the scaffold task brief.

## Global Constraints

- Base: `/ZAEBALPORTFOLIO/`.
- Russian interface copy, named exports, strict TypeScript, `noUnusedLocals: true`.
- Exact tokens from `TOKENS.md`; only paper, ink, neutral ramp, and scarlet.
- Reduced motion removes transforms, stops loops, and limits fades to 150ms.
- Missing project decision bodies remain empty; no invented facts.
- Full page content, generated artwork, deployment workflow, and cover images are out of scope.

## Review Focus

- Nested and unknown routes work under the deployment base.
- Mobile menu traps focus, closes with Escape and route changes, and restores focus.
- Reduced-motion users see all content without movement.
- Layout fits 360, 768, 1280, and 1600px without horizontal scrolling.
- Missing project slugs show a useful fallback; missing cover assets are not requested.

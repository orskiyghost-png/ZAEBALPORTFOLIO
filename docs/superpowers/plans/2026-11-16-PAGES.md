# Portfolio Pages Implementation Plan

> **For agentic workers:** Execute these tasks in order in the current session. The user explicitly requested implementation without further approval or delegation.

**Goal:** Replace every placeholder route with the complete Russian editorial portfolio specified in the implementation brief.

**Architecture:** Retain the existing React Router shell, motion primitives, tokens and shared reveal observer. Keep project facts in typed data, share image reveals and selected-work cards, and place all page styling in `src/styles/app.css`.

**Tech Stack:** Vite, React, TypeScript, React Router, Motion, plain CSS.

**Spec:** `DESIGN.md`, `MOTION.md`, `CONTENT.md`, `TOKENS.md`, and the user's full-page implementation brief.

## Global Constraints

- Paper `#F7F4EF`, ink `#141110`, scarlet `#E01B0B`; no new accent, chrome gradients, glass or glow.
- Russian copy, `«»` quotes, no invented outcomes, clients or metrics.
- Named exports, strict TypeScript, existing tokens and reduced-motion hook.
- Animate only transform and opacity. Use a static clip boundary and transformed paper shutter instead of interpolating clip-path.
- Use existing `.jpeg` artwork and resolve every URL relative to `import.meta.env.BASE_URL`.
- Build and type-check before each push; commit only this task's changes on `main`.

## Review Focus

- All six project slugs and images resolve, including `tihiy-chas`, under the deployment base path.
- Long Cyrillic headings, stack chips and project types do not overflow at 360, 768, 1280 or 1600 px.
- Reduced motion exposes all content, stops parallax and avoids hidden image masks.
- Filters include research concepts and preserve visible keyboard focus.
- Clipboard failure has honest accessible feedback, and FAQ works without JavaScript.
